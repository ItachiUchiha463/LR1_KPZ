# Довідкові матеріали

## Словник термінів

| Термін | Значення |
|---|---|
| Діагноз | Висновок системи про проблему. Описаний у [довіднику діагнозів](knowledge-base.md): назва, критичність, опис, рекомендація |
| CF (упевненість) | Число від 0 до 1: наскільки система впевнена у висновку. Кілька незалежних підтверджень комбінуються формулою CF₁ + CF₂ × (1 − CF₁). Докладніше: [Впевненість правила](knowledge-base.md) |
| SEV | Рівень інциденту від SEV1 (найтерміновіший) до SEV4. Залежить від критичності діагнозу, ваги сервісу й тривалості. Докладніше: [Рівні SEV](diagnostics.md) |
| raw (вхідний показник) | Показник, значення якого вводить користувач або надсилає агент, наприклад `завантаження_CPU_%` |
| derived (проміжний стан) | Факт, значення якого виводить правило з інших фактів, наприклад `тиск_на_памʼять`. Докладніше: [Вхідний показник і проміжний стан](knowledge-base.md) |
| Шар виводу | Номер етапу виводу. Правила шару 1 читають вхідні показники, правила шару 2 і вище — результати попередніх шарів |
| Значення за замовчуванням | Значення проміжного стану до початку виводу, зазвичай «норма». Докладніше: [Значення за замовчуванням](knowledge-base.md) |
| Нерухома точка | Стан, коли жодне правило більше не додає нових фактів; тоді вивід зупиняється й видається результат |
| Робоча памʼять | Сховище фактів поточного прогону: вхідні показники й виведені стани. Для кожного прогону створюється заново |
| Трасування | Журнал спрацьованих правил: яке правило, на якій ітерації, за якими умовами й що вивело. Дозволяє пояснити діагноз |

## Немає з'єднання з бекендом

Повідомлення «Немає з'єднання з бекендом (localhost:8000)» або червоний індикатор угорі означає, що сторінка не отримала відповіді від сервера діагностики.

Перевірте:

1. Чи запущено сервер: у папці `backend` виконайте `py -m uvicorn main:app --reload --port 8000`.
2. Чи відкривається `http://localhost:8000/api/health` у браузері.
3. Чи доступна MongoDB: у відповіді `/api/health` поле `mongo_connected` має бути `true`.

Після виправлення виконайте **Система › Перевірити з'єднання з бекендом**.

## Помилки збереження (409 і 422)

- **409** — елемент із такою назвою чи кодом уже існує. Оберіть іншу назву або відкрийте наявний елемент.
- **422** — поле заповнено неправильно (наприклад, CF поза межами 0–1). Повідомлення вказує поле й причину.
- Додали факт чи діагноз, а на сторінці «Діагностика» його немає — перезавантажте сторінку (F5).
